# Calculadora ElevaTech

Calculadora estática de divisão de recebimentos: 25% comercial, 30% produção e 45% empresa por padrão. Comercial e produção são editáveis; empresa recebe o restante. Os valores são calculados em centavos e sempre fecham com o total recebido.

Resultado instantâneo, histórico local, cópia do resumo e exportação CSV. Layout responsivo com a logo e as cores da ElevaTech.

O histórico usa localStorage e fica exclusivamente no navegador/dispositivo utilizado, sem sincronização ou envio ao GitHub. Exporte o CSV para backup. O site não contém dados de projetos reais.

Abra index.html ou sirva esta pasta com um servidor estático. Publique no GitHub Pages a partir da raiz da branch main.
